Used only to read the text of Khmer PDFs (matching a PDF's embedded font by
its glyph outlines); they are not offered as fonts for editing. Each font's
copyright is in its own name table.

6.00 fonts Word documents embed as "Khmer OS Content", "Khmer OS Siemreap",

glyphs differ.
